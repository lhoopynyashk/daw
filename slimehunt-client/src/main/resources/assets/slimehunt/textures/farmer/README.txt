Seed/plant art (recommended 128x128):
recipes/<seed-id>.png
Example: recipes/seed_sweetroot.png
For spores use the full ID, for example recipes/spore_night_cap.png.

Ingredient art (recommended 64x64):
items/<item-id>.png
Examples: items/res_soft_soil.png, items/plort_moss.png

Transparent PNG files work best. Rebuild :slimehunt-client:bundle after adding files.
